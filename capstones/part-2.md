## Deliverables / observable behaviors

- Demonstrate a website with clear boundaries for public assets versus private lab information.
- Demonstrate the defensive browser-extension prototype with minimal permissions and an isolated Kali VM environment used only for authorized testing.
- Present Lighthouse findings with at least one concrete remedial action.
- Demonstrate **your own** local SQLite knowledge tree, a functioning handmade lookup interface, safe search/filter behavior, cross-links and source records, plus backup/restore.
- Confirm private notes database is not published, no secret is exposed, and hosting/sharing/HTTPS/ports have been checked.
- Present an incident/rollback walkthrough. **No AI controls the website in Part 2.**
- A failed safety gate must be fixed before progressing to Part 3.

## Submission package

- Learner's own explanation of the system and decisions
- Evidence folder or a clear commit reference
- Test plan, reproducible test output and failure/recovery notes
- Source citations in the SQL tree when appropriate
- Security-gate decision and retest evidence, if applicable
