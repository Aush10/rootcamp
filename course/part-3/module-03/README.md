For **each** subject: named-author required reading → supplementary options → AI explanation → ungraded functional exercise → notes/evidence. When all subjects are visited, conduct **one graded module assessment** (open-note, method chosen to suit the material).

Practice locally or in explicitly authorized test environments. Extra investigation belongs on the rabbit-hole register. Part 1 programming work is learner-written; automated coding help begins only at P3M3.
